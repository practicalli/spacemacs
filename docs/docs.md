# Documentation Tools

![Markdown logo](https://github.com/practicalli/graphic-design/blob/live/logos/markdown-logo.png?raw=true){align=right loading=lazy style="width:150px"}


[Markdown](./markdown-mode/index.md) is an easy to adopt markup that is an excellent choice for writing, especially large amounts of content.

Practicalli uses Python flavor of Markdown to create a rich user experience with [Zensical](https://practical.li/engineering-playbook/technical-writing/static-site/zensical/){target=_blank}

---

![Emacs Org-mode](https://raw.githubusercontent.com/practicalli/graphic-design/59d72259f4900798427b06a7d9452960eadc5967/icons/org-mode-unicorn.svg){align=right loading=lazy}

[Emacs Org Mode](./org-mode/index.md) is not just a tool to write documents, it can be used to keep notes, create computational notebooks, develop interactive literate programming docs, maintaining to-do lists, planning projects, etc.

All these features work with a fast and effective plain text system.
